## Probe boundary

The Phase 5 probe records repository availability and a small sample of vehicle components in `ui-source-probe.json`. It does not enumerate or invoke unknown engine-system methods, because an unsupported call can destabilize the game. A source is promoted to `ENGINE_AVAILABLE` only after a read-only call succeeds in the live save; a UI semantic claim additionally needs a same-save UI comparison.

## Acceptance evidence required to promote UI metrics

For each proposed numeric metric, capture three samples with the entity ID/name and visible value, then obtain a snapshot at the same simulation time. The collector may expose the field only when all three pairs agree on unit and meaning. Phase 4 supplies the three line and vehicle UI samples above, but those do not yet have matching engine-side values.

### 已确认依据与边界

- 国家铁路局《铁路技术管理规程》第 31 表给出单开道岔侧向允许速度；新版《铁路技术管理规则（征求意见稿）》继续要求按侧向最高速度选用辙叉号数。控制模型据此使用道岔档案，不把 200 km/h 轨道资源速度当成所有站场侧向进路的运行速度。
- Transport Fever 2 当前可观测数据包含全局边／节点拓扑、边限速、站台边、线路路径、列车实时边位置、速度、下一站和站台锁定状态，但没有直接暴露中国铁路道岔号数。因此自动识别结果必须标注为推断，并允许人工覆盖。
- 官方 Lua API 已用于运行图扣停／放行及可用的线路操作；单车区间限速、进路代价和进路锁定前的站台干预继续由版本签名锁定的原生模块执行。
- “全盘接管”是受监督的闭环控制能力，不绕过游戏自身的可达性、信号、方向和碰撞校验；平台可以改变速度上限、候选路径代价和站台选择，但不构造游戏判定为非法的轨道路径。
